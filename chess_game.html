Set up Firebase in this file to enable online play.

Setup: create a Firebase project, enable Anonymous sign-in and Realtime Database, then paste your web app config into firebaseConfig in this file. Configure database rules for authenticated players before publishing.

Example Realtime Database rules 
{
    "rules": {
        "games": {
            "$gameId": {
                ".read": "auth != null",
                ".write": "auth != null && (!data.exists() || data.child('players/w').val() == auth.uid || data.child('players/b').val() == auth.uid || (!data.child('players/b').exists() && newData.child('players/b').val() == auth.uid && data.child('players/w').val() == newData.child('players/w').val()))"
            }
        }
    }
}

This limits existing game writes to seated players and allows one authenticated guest to claim Black. With no trusted backend, browser code cannot fully prevent a player from tampering with game data. For ranked or adversarial play, validate moves server-side.
